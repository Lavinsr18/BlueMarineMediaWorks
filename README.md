# Blue Marine Mediaworks — Magnetto Theme Adaptation

This version intentionally keeps the supplied Magnetto visual language: large rounded hero containers, monochrome photography treatment, floating pill navigation, oversized editorial type, large rounded project cards, glass overlays, white/black sections, marquee strips and restrained motion.

Only the content, branding, service information, project names and placeholder imagery have been adapted for Blue Marine Mediaworks.

Run:

npm install
npm run dev
